# IntelliTrack Client — Criminal Intelligence & Investigation Frontend

Modern, high-performance tactical intelligence dashboard and investigation workbench built with **React 19**, **Vite**, **Tailwind CSS**, and **Three.js**.

---

## 🏛 Overview

IntelliTrack Client provides an intuitive, high-security user interface for criminal intelligence analysts, tactical officers, and lead investigators.

### ✨ Key Features
- **Investigation Overview & Cockpit**: Real-time KPI telemetry, threat tier monitors, active investigation cases, and priority leads.
- **Entity Resolution Workbench**: Graph-based entity deduplication, alias matching, and biometric identity resolution.
- **Network Analysis**: Interactive 2D/3D criminal network visualization and community cluster detection.
- **Geo-Temporal Intelligence**: Event timeline scrubbing and geographic pattern tracking.
- **Cryptographic Evidence Ledger**: Bates stamping, Merkle tree verification, and tamper-evident chain-of-custody tracking.
- **Court-Admissible Dossier Export**: Automated PDF preview and evidentiary report compiler.

## 🚀 Getting Started

### Prerequisites
- **Node.js**: `v18+` or `v20+`
- **npm** or **yarn**

### Installation

```bash
# Clone the repository
git clone https://github.com/Mustu55/IntelliTrack_client.git
cd IntelliTrack_client

# Install dependencies
npm install
```

### Running Locally

```bash
# Start development server
npm run dev
```

The frontend will run on [http://localhost:3000](http://localhost:3000).

### Build for Production

```bash
# Compile and bundle
npm run build

# Preview production build
npm run preview
```

## 🛠 Tech Stack

- **Framework**: React 19 + Vite 6
- **Styling**: Tailwind CSS + Custom Dark Cockpit Theme
- **State & Data**: Redux Toolkit, TanStack React Query
- **Visuals & 3D**: Three.js, GSAP, Framer Motion, Lucide Icons, Recharts
- **Networking**: Axios, Socket.IO Client
